# Recipe App

A simple Android app for organising cooking recipes.

Recipes are supplied to the app as JSON files. For each recipe the app shows:

- a clear list of the ingredients required
- step-by-step cooking instructions

## Status

Early setup. The first milestone is an app with a placeholder design that can add JSON recipe files and read the saved ones.

## JSON format

Not defined yet. The exact format will be agreed once the app can add and read saved JSON files, so that the format follows what the working app teaches.

## Project plan

1. Version-controlled project on GitHub (this repository)
2. Android app skeleton with a placeholder design
3. Add and read saved recipe JSON files
4. Define the recipe JSON format
5. Ingredients view and step-by-step instructions
6. App design
